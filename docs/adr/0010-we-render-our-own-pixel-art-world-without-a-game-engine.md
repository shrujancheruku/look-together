# We render our own pixel-art world, without a game engine

Look Together's pond, from the welcome to home, Inquiries and Recaps, is pixel art that our own code draws: one small world, built on the device from the Inquiry's records, drawn by React Native Skia at art resolution and scaled up by a whole number with nearest-neighbour sampling, with all text, input, dictation and accessibility left native on top. Sky, water, light and motion are drawn by code; a few hero pieces (the lotus, pads, the boat) are drawn by hand or generated and stored as indexed colour, so seasons, time of day, Still water and the Step-out are palette swaps rather than new paintings. A director turns changes in the Inquiry's records into short cues and never writes back, so [ADR 0004](0004-inquiry-is-an-app-owned-state-machine.md) holds, and each lily is grown from its Inquiry on the device in integer maths, so nothing leaves it ([ADR 0003](0003-inquiry-content-never-on-our-servers.md)). We chose this over painted watercolour layers, the earlier direction, because side by side on web the pixel pond was much better, and it is far lighter: about 0.3 MB of decoded art against about 67 MB, with no full-screen blur behind each card. We chose it over pixel art shipped as finished images because a world drawn from state can show each Inquiry as it is. We rejected a game engine, embedded or running the whole app: Unity as a Library only renders full-screen on mobile, Godot's LibGodot shipped for desktop only, and Defold isn't built to be embedded. Each would add a second runtime, a second asset pipeline and a separate web build, and an engine-drawn interface would lose native text, dictation and screen readers. The pixels serve a calm, soft, somewhat nostalgic mood, never a retro-game homage, and nothing in the world rewards, counts or compares. The cost is more work, roughly 9–16 weeks against 5–9 for painted images, most of it the hero art. Web may also have to shade every screen pixel instead of drawing offscreen, since reading an offscreen image back costs about 18 ms a frame there.
